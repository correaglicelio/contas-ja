# Contas Já

Quanto dinheiro o governo federal repassou à prefeitura do seu município, comparado com o mesmo período do ano passado. Dados abertos do Portal da Transparência (CGU).
Faz parte do **Hub Já**: https://hubja.com.br/contas-ja/

O painel mostra o que foi **repassado**, não o que a prefeitura gastou. Não inclui ICMS/IPVA (do estado), arrecadação própria nem Bolsa Família.
